# Shipping review and model handoff — 16 September 2026

This is a ranked list of ten concrete findings from this release review. “Fixed” means addressed in the current website change; open limitations are not represented as passing checks. Do not weaken iframe isolation, owner authorization or publication review to clear a finding. Do not recreate official games to work around update failures.

| Priority | Finding | Status / evidence | Next action and acceptance |
|---|---|---|---|
| 1 | MCP revisions do not preserve an already published game's identity. | **Open capability gap.** `supabase/migrations/20260914170000_slop_mcp_bridge.sql:165–168` creates a fresh slug per revision; `src/lib/mcp-publication.js:32–42` prepares that draft without a canonical update target. Live QA confirmed distinct IDs/slugs for two revisions. | Add an owner-bound MCP project → canonical game relationship and the existing update-candidate publication flow. Publish v1, approve v2, and prove the public ID/claimed name stay the same while both private preview revisions stay immutable. |
| 2 | Desktop games lose local saves when their player closes. | **Open.** `src/lib/player-storage.js` substitutes per-frame Maps for both storage APIs. Slopcraft's authored claim that edits save on this device is therefore misleading across player mounts. | Add a bounded, owner/game-scoped host persistence bridge, or accurately label session-only saves until that exists. Build/mine, close, reopen and verify restoration plus isolation between accounts/games. Never grant game frames access to site authentication storage. |
| 3 | Normal creator publication has not been verified all the way through moderation to a public game. | **Verification gate.** Real creation, repair, edit, playtest, recording and upload passed. The real pending-review SQL finalizer passed inside rollback; the QA forwarding layer stopped notifications. This is not proof of ordinary moderation or a public QA release. | Run one deliberately approved release through normal owner submission and moderation. Verify the final public API row, immutable source/runtime/media, claimed link, website playback and phone playback. See `../creator-customization-qa-2026-09-16.md`. |
| 4 | Late creator responses can change the route or selected project after navigation. | **Fixed in this release.** The initial code rewrote history after asynchronous admission/load/feedback without an unmount-aware operation ticket. | Retain operation-start tickets, invalidate on unmount/project changes and run the delayed-response contract tests. Preserve idempotency: a timeout must not silently create a second billable run. |
| 5 | Unavailable browser storage can trap the Build form before any API request. | **Fixed in this release.** The original pending-request `sessionStorage.setItem` ran outside the error handler after the form was marked busy. | Keep quota/disabled-storage handling ahead of admission, clear busy state, preserve the prompt and show a recoverable error. Run the quota-failure test. |
| 6 | The generated-game guide permits an easy high-DPI drawing mistake. | **Open prevention gap; observed game repaired.** A real generated game reset the canvas transform and rendered at half scale with incorrect pointer targeting. Same-run feedback repaired it. Mobile `live-games/slop-sdk/CREATOR.md:26–30` describes DPR but omits transform preservation. | Add: “Preserve the SDK's DPR transform with balanced ctx.save()/restore(); if you reset the transform, restore ctx.setTransform(view.dpr,0,0,view.dpr,0,0) before drawing in CSS pixels.” Sync the authoring guide with its existing generator, deploy through the normal mobile/backend process and playtest high-DPI pointer hits. |
| 7 | Public game links return HTTP404 and generic homepage metadata. | **Open distribution issue.** Fresh GET of `https://slop.game/run-infinite-desktop` returned HTTP404 with homepage canonical/Open Graph values. JavaScript still opens the game, but crawlers/link previews receive a404. `tools/postbuild-routes.mjs` copies the SPA to404.html; `index.html` contains global metadata. | Serve claimed game routes with 200 and per-game title/image/canonical data. Verify newly published names immediately, without requiring a static-site rebuild for every game. Keep unknown names 404. |
| 8 | Discover People opens with the wrong backdrop before switching. | **Fixed in this release.** Discovery omitted `profile_banner_id`; detail fetch replaced the initial fallback. | Keep shared public profile columns and the native backdrop mapping. A card's initial opened profile and its refreshed details must use the same known equipped backdrop. Null uses the native Forest default. |
| 9 | Signed-out You still played the old bouncing character video. | **Fixed in this release.** The user's exact page had no native iframe and played `ghost-tangerine-idle.webm`. | The guest view now uses the exact native eye portrait with a stationary body. Keep both guest and authenticated You calm; retain manual rotation/customization for authenticated profiles. |
| 10 | Unseen customized looks can lose fidelity on Social portrait fallbacks. | **Open new-look path.** `NativeEyePortrait.jsx` animates only exported signatures. `slop-avatar.js` tries a finite native atlas; when no matching portrait/atlas exists, `ui.jsx` falls back to a basic shape/palette image. Current first Social page 24/24 matches, so this is not a claim that the current grid is wrong. | Generate/cache an exact native portrait for new saved appearance signatures, with bounded costs and invalidation. Test a new material/accessory combination absent from both catalogs; its Social portrait must match its opened native profile. |

Additional smaller findings: Social profiles display only the first 24 games despite a larger count (observed 42 for one creator); NativeSlop has no bounded engine-failure retry; Feed retains every visited card and remeasures them on scroll. These should be tested and prioritized after the identity, save and publication gates. The homepage pagination response is now fenced against filter changes. The Night Drift mobile composition has additional reserved space above its controls.
