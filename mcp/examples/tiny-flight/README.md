# Tiny Flight

A tiny cross-platform Slop.js game: hold to climb, release to glide, and clear five rings.

- Phone: touch and hold anywhere.
- Desktop: hold the mouse button, Space, W, or Arrow Up.
- Runtime: unchanged `creator-v1` Slop.js from `slop_game_template`.
- Target: `cross-platform` (`mobile` and `desktop`).

Serve this directory over HTTP and open `dev-harness.html` for local lifecycle testing. Upload `index.html`, `game.js`, `slop.js`, and `slop-platform.json` as the private MCP draft bundle; the harness and this README are repository-only files.
